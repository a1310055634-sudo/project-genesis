# 压力场景包（Roadmap 后续批次 C，2026-09-17）

> 目的：检验模型在非默认参数下不产生荒谬状态（NaN/负人口/invariant 违规），
> 并记录极端条件下的行为画像。全部跑经 `checkInvariants: true`，零违规。
> CLI 已补 `--employmentRate` 场景直通（与 `--birthProbabilityPerMonth` 同款）。

## S1 极端失业 — employmentRate 0.3（默认 0.62），10k×5y

- 生成期就业率精确落地（实测 0.299）；5 年人口 9,518，人均财富 $20.9k
- 压力/幸福感通路正常运转（strain 高分母下未见异常值）
- 清真度：无 NaN，人口动态平滑

## S2 零生育老龄化 — birthProbabilityPerMonth 0，10k×50y

- 10,000 → **2,795**（纯死亡衰减，children 归零、seniors 970）——人口学教科书式老龄化
- 与主百年跑互为印证：**即便有生育，社会也在收缩；没有生育则 50 年剩 28%**
- 反向确认了崩塌诊断：生育-婚姻耦合是唯一的世代更替通道

## S3 微型社会 — 50 人×50y

- 22 alive / 57 ever-born——微型社会可自我维持但同样受生育门槛压制
- 无 NaN/崩溃；社交织构完整（162 条边，孤立率正常）

## S4 超大规模 — 50,000 人×5y

- **4,806 万事件**全程无 invariant 违规；内存/时长可接受
- 动力学与 10k 基线一致（mean stress 0.459 vs 0.456）——**模型行为随规模平滑缩放**
- KI-2a/b 优化的规模线性度得到实测支撑

## 结论

四场景零荒谬状态。模型的"舒适区外"行为（极端失业、零生育、微型、超大）全部落在
人口学上可解释的区间。场景包纳入常规回归范围（每次引擎大改后重跑）。
